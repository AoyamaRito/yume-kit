# デザイン講義（ローカル）

- **HTML**: [`../design-lecture.html`](../design-lecture.html)
- **テーマ**: 「デザインとは、情報の整理である」
- **形式**: 16:9 スライド（1280×720 スケール）

## 講義の骨格（オフライン要約）

1. 誤解を解く — 装飾ではなく整理
2. 3 つの問い
   - 誰に
   - どんな情報を
   - どう伝えるか（重要度の差を見た目の差に）
3. 事例（グラフィック / ゲーム / 工業）
4. 基本道具 — 視線の流れ、余白によるグループ化、目立たせたいか？
5. 失敗パターン 3 つ
6. 実践 — 作る前に 3 行書く
7. 結論 — デザイン = 情報の整理
