# 実況凄腕営業マン — カードイラスト スタイルガイド

- **正本**: `../../実況凄腕営業マン/assets/STYLE_GUIDE.md`
- **SET 版**: `../../実況凄腕営業マン/一懐に入る編/assets/STYLE_GUIDE.md`
- **用途**: カードキャラ生成プロンプト（UI コンポーネント DS ではない）

## 全体方針

- 一目で人物像がわかる
- **背景なし**・人物だけ大きく
- デフォルメ寄り。リアルさより伝達
- 全セットでタッチ・色味・線質を統一

## 共通プロンプト核

Clean stylized deformed Japanese board game card character illustration, big expressive head, bold clean linework, limited palette (deep teal, energetic warm orange-red `#E85D04`, soft cream, neutral beiges), no background, vertical **2:3**, character large centered, no text/logos.

## 技術

- アスペクト 2:3 縦
- バスト〜ウエストアップ
- テキストはイラスト内に入れない
