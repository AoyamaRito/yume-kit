## グリッド

- 水平・垂直とも **14 等分**
- 外側左右（上下）: **1u マージン**
- 内側コンテンツ: **12u**
- `grid-column: 2 / 14` が標準コンテンツ列
- 典型レイアウト: 左メイン `2 / 10` + 右囲み `10 / 14`
- `gap: 20px` 以上

```css
.main-grid {
  display: grid;
  grid-template-columns: repeat(14, 1fr);
  gap: 20px;
}
.content { grid-column: 2 / 14; }
```

## タイポ

| 役割 | 目安 |
|------|------|
| big-title | 56px |
| hook-text | 21px |
| 本文 | 12–13px / line-height 1.55+ |
| ヘッダー小 | 9–12px |
| 左上 名前日付 | text-2xl 以上（必須） |

フォント: Noto Sans JP / Inter / system-ui

## 余白原則

- 要素を近づけすぎない（ちかすぎ NG）
- box 内 padding **22px 18px** 以上
- grid gap **20px** 以上
- ステップ間 margin-bottom 十分

## 囲み記事

```css
border: 2px solid #B89F5F;
border-radius: 4px;
padding: 22px 18px;
background: #0A1C3A;
```

## ヘッダー

- 固定トップバー
- 左上: 名前　日付（例: 沖井広行　2026.06）
- 続けてタグ。右側にメタ UI を出さない

## スライド

- `min-height: 100vh; scroll-snap-align: start`
- 横長 16:9 相当、wide-container max-width ~1600px

## クリーンさ & PDF

- HTML 一次ソース
- UI に「HTMLソース」「PDF保存」等のメタを出さない
- ブラウザ印刷 landscape で PDF 化
