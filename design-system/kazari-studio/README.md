---

## 💎 特徴 & コア美学（`@design/` 思想準拠）

1. **直列 3 ステップ完走（往復ゼロの一本道）**
   - **Step 1: 入れる** — メイン文字、ルビ、サブ欧文、章番号を投入。横書き/縦書き即時プレビュー。
   - **Step 2: 選ぶ・整える** — 8大プロ品質プリセットから1クリック選択。微調整は折りたたみ枝葉UIに格納。`[スキップして書き出す →]` で即座に完了可能。
   - **Step 3: 受け取る (DONE)** — DONE静寂Dim（明度フィルター）と中央の焦点刻印。透過PNG / ベクターSVG / CSS / Unicode装飾テキストを一撃で獲得。
2. **線の省略と急所の線（用の美）**
   - 外枠の檻を全廃し、呼吸する余白と面、1pxの触れる境界・朱の背骨線のみで構成。
   - 伝統色 1 色切り替え（朱 `--accent-vermilion` / 藍 `--accent-indigo` / 金 `--accent-gold`）。
3. **Marching Dotted Frame & エラーShake**
   - 処理中カードを 5px 丸ドットの点線が静かに周回。
   - 未入力での進行時には微細振動（Shake 200ms）＋朱のベール（Red Tint）で直感伝達。
4. **左右 HUD バー（常時キーボード案内）**
   - `[Esc]` 戻る / `[Space]` スキップ / `[⌘+↵]` 次へ・完了 / `[⌘+S]` PNG保存 / `[⌘+E]` SVG出力 / `[⌘+C]` 画像コピー。
5. **多彩なエクスポート**
   - **透過 PNG (4x Retina)**: 印刷・動画サムネ・同人誌用の超高解像度透過画像。
   - **ベクター SVG**: 拡大しても劣化しないグラデーション・フィルター内蔵SVG。
   - **Web用 CSS スニペット**: コピペでそのまま使える `background-clip: text` & 多段 `text-shadow`。
   - **SNS用 装飾テキスト**: 特殊Unicode文字＋装飾罫線。

## 👑 8大プロ品質プリセット (Sane Defaults 80点)

| プリセット名 | スタイル特徴 | 主な用途 |
|--------------|--------------|----------|
| **① 墨漆と落款 (Sumi & Seal)** | 伝統の墨黒・かすれ質感・朱の落款（角印） | 和風・歴史・文芸・企画書見出し |
| **② 金箔と真鍮 (Gold Foil & Brass)** | 黄金メタリックグラデーション・3Dベベル彫刻・王冠 | 高級感・表彰・タイトルロゴ・ゲーム |
| **③ 藍碧クリスタル (Indigo Crystal)** | 藍色〜深青グラデーション・氷晶発光グロー | 知性・IT・ビジネスプレゼン・SF |
| **④ 多重極太フチ (Pop & Anime Stroke)** | 白インナー＋黒アウター極太フチ＋立体影 | ラノベ・同人誌・YouTubeサムネイル |
| **⑤ 浮彫り3Dレリーフ (3D Emboss)** | 多段立体押し出し・深いアンビエントシャドウ | 重厚感・記念碑・立体ロゴ |
| **⑥ 電撃ネオン (Cyber Neon)** | 多層ガウス発光・サイバーシアン・エッジライト | 近未来・サイバーパンク・クラブイベント |
| **⑦ 幾何学ミニマル (Swiss Minimal)** | フィボナッチ余白・急所の朱の背骨線・スイススタイル | モダンデザイン・ポートフォリオ・建築 |
| **⑧ 伝統短冊・水引 (Tanzaku & Ribbon)** | 和風帯封・飾り水引・短冊見出し枠 | 和菓子・祝い事・伝統行事告知 |

## 📁 ディレクトリ構成

```text
kazari-studio/
├── index.html       ← 単機能・直列WebアプリUI（直列3Step、左右HUD、静寂Dim、Marching Dots、Shake）
├── style.css        ← PHILOSOPHY.md準拠のCSS（フィボナッチ、線の省略、伝統1色切替）
├── engine.js        ← 飾り文字描画コア（Canvas 2D + SVG生成 + CSS生成 + Unicode装飾変換、縦横約物処理）
├── app.js           ← フロントエンドコントローラー（直列遷移、ショートカットキー、エクスポート処理）
├── test.js          ← 単体テスト・レンダリング・SVG生成・エクスポート検証
├── e2e.mjs          ← 自然言語シナリオE2Eテストスイート
├── package.json     ← パッケージ定義
└── README.md        ← 本解説ドキュメント
```

## 🚀 起動方法 & テスト

```bash
# 1. 単体テスト実行
node kazari-studio/test.js

# 2. 自然言語 E2E Snowball テスト実行
node kazari-studio/e2e.mjs

# 3. ブラウザでアプリを開く
open kazari-studio/index.html
# またはローカルサーバー
python3 -m http.server 8765
# → http://localhost:8765/kazari-studio/
```
