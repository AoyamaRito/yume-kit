14U グリッド デザインシステム

実況 凄腕営業マン プレゼン資料 用ルールブック

概要

このシステムは横長画面向けの14等分グリッドを基盤とし、余白を重視したクリーンなデザインを実現する。HTMLを一次ソースとし、印刷でPDF化可能。

グリッドシステム

水平・垂直ともに14等分

1グリッド = 余白の基本単位

  • 外側左右上下: 1u マージン (余白用)
  • 内側: 12u コンテンツエリア
  • 合計: 1 + 12 + 1 = 14

理由: 12は2/3/4/6/12で割りやすい。14で外余白を確保しつつ柔軟。

CSS実装
.main-grid {
  display: grid;
  grid-template-columns: repeat(14, 1fr);
  gap: 20px;  /* 内部余白 */
}
.content {
  grid-column: 2 / 14;  /* 外1uを避ける */
}

ベース参考: 1080×1920 (縦型) を横長 (16:9 など) に適応。wide-container で max-width 制御。

余白の原則 (余白大事)

要素を近づけすぎない。ちかすぎはNG。

  • padding / margin / gap を u 単位で (例: 20px+ ≈ 1u+)
  • box 内: padding 22px 18px 以上で呼吸させる (ちかすぎ厳禁)
  • grid gap: 20px 以上推奨
  • 左コンテンツ (2/10) と右囲み (10/14) の間: grid gap でしっかり確保

14u の精神: 外1uマージン + 内部も余裕を持たせる。

ヘッダー (左上必須)

固定トップバー

左上: 名前　日付 (text-2xl、通常の約2倍サイズ以上)

例: 沖井広行　2026.06

その後: タグ (営業部署向け / 暗黙知共有 × チームビルド)

右側に余計なメタ (PDF保存など) は置かない。クリーンに。

囲み記事

補助情報 (プレイの仕方、コンポーネントなど) をボックス化。

border: 2px solid #B89F5F;
border-radius: 4px;
padding: 22px 18px;
background: #0A1C3A;

内部 (余白多め):

  • 小ラベル「囲み記事」 (9px)
  • 見出し (14px)
  • 本文リスト (13px, line-height 1.6, ステップ間 margin-bottom 16px)
  • 下部コンポーネント (10.5px, padding-top 10px)

右側 (grid 10/14) に配置。左メイン (2/10) と grid gap で分離。

タイポグラフィ & カラー

カラー

  • --navy: #0A1C3A
  • --gold: #B89F5F
  • --orange: #E85D04

サイズ例

  • big-title: 56px
  • hook-text: 21px
  • 本文: 12-13px (line-height 1.55+)
  • ヘッダー小: 9-12px
スライド & レイアウト

各スライド: min-height: 100vh; scroll-snap-align: start;

横長画面 (16:9 相当) 向け。wide-container (max-width: 1600px)

14u でコンテンツをグリッド配置。左メイン (grid-column: 2 / 10) + 右囲み (10 / 14) の典型構成。余白を意識した gap と padding を多用。

クリーンさ & PDF

UIにメタ情報 (「HTMLソース」「PDF保存ボタン」など) を出さない。

HTML を一次ソースに。ブラウザ印刷 (landscape) で PDF 化。

印刷用 CSS は残すが、説明テキストは最小限。

実装チェックリスト (余白・一貫性)
  • 外側1uマージン確保 (content 2/14)
  • grid gap 20px 以上
  • box 内 padding 22px 18px 以上で呼吸 (ちかすぎ厳禁)
  • 左メイン (2/10) と右囲み (10/14) の間隔を grid gap でしっかり
  • ヘッダー左上 名前日付 text-2xl 以上
  • 遊び方など本文 13px+、line-height 1.6 以上
  • 要素間 margin-bottom 十分 (10px+)
  • 全体的に余白を意識して「ちかすぎ」チェック
