## 前提知識（押さえておいて）

- Block = `{ id, type, versions[] }`。`versions[]` は append-only で直近32版キャップ。
- expand = 編集用の「厚いビュー」（マーカー境界 + hash付き）。apply = 本文だけ検証して新版に append。
- マーカーはコメント行（`//` か `#`）→ どの言語でも同じ境界を使える。
- domain-tag = 値にドメインを埋める自己記述（`usd:1299` 等）。
- **並列化の仕組み（複数AIで1つの共有状態を分割する装置）は意図的に入っていない。**
