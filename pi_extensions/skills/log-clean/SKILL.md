# log-clean — 入力の清書（ログ用・常時適用）

ユーザーの生入力（ローマ字・漢字未変換・かな混じり）を、**意味を一切変えずに**読みやすい日本語へ清書し、ログに載せられる形で返す。**常時適用**：依頼を待たず、ユーザーの生入力はその場で即座に清書してから解釈・処理・記録する。

## 基本ルール（上の方が強い）

1. **意味は一切変えない**（最優先・絶対条件）
2. **文字もできるだけ変えない** — 変換不足の補正（ローマ字→日本語表記、未変換かな→漢字、半角→全角）と、読みやすさのための句読点・記号・改行の整理だけ。言い回し・語順・口調・省略は変えない
3. **確定できない時は勝手に決めない** — 候補を3つ提示して聞き直す
4. **ローマ字入力は想定済み** — ローマ字をそのまま日本語表記へ戻す

## 作業手順

1. 生入力をそのまま受け取る（変えない）
2. 意味が確定できるか判定:
   - 確定できる → 清書する
   - 確定できない → 候補3つを提示して聞き直す（下記フォーマット）
3. 清書結果をログに貼れる形で返す

## 清書で直してよいもの（これだけ）

- ローマ字 → 日本語表記（`konnichiwa` → こんにちは / `kyou` → 今日）
- 未変換かな → 漢字かな交じり（あすの12じ → 明日の12時）
- ひらがな/カタカナ/半角カナの揺れ → 標準表記
- 句読点・空白・改行の整理（読点の追加削除は読みやすさ優先で OK）
- 数字・日付・時刻の表記統一（12時 / 2026年9月2日 など、原文に合う範囲で）
- 明らかな打ち間違いの修正（誤字のみ。意味が変わる補正はしない）

## 清書で変えてはいけないもの

- 言い回し・語順・助詞（パラフレーズ禁止）
- 口調（くだけた言い方・命令・疑問はそのまま）
- 省略・略語（補わない。省略は省略のまま）
- 固有名詞・専門用語（読みが確定できないものは触らない）
- 意味の追加・削除・言い換え

## 意味不明時の候補提示フォーマット

```
【この入力、意味が確定できません。どれが近い？】
入力: <原文のまま>

1. <候補1>
2. <候補2>
3. <候補3>
（それ以外の解釈があれば書いてくれると助かる）
```

- 候補は「原文の文字を最小限の補正で読める解釈」を3つ。いちばんありそうなものを1番に。
- 1回の聞き直しで確定すればそれで終わり。長引かせない。

## 出力フォーマット（清書確定時）

```
【清書】**<清書文>**
原典: <生入力をそのまま>
```

- **清書文 = マークダウン太字（`**`）で強調**。ログに載せられる本体はこちら
- **原典 = 別行に `原典: ` を付けて生入力のまま併記**。装飾はしない（目立たせない）
- **HTML タグ（`<sup>` `<sub>` 等）は使わない**：環境によって素タグが露出し、折り返しで文が割れるため（実績あり）
- 原典は「何を変換したか」を確認するための添え物。清書文と同列以上に目立たせない

## 例

| 清書（ログに貼る） | 原典（生入力） |
|---|---|
| **明日の12時に会議してほしい** | asita no 12ji ni kaigi site hoshii |
| **近況の進捗は確認できたよ** | きんきょうのしんぽはかくにんできたよ |
| **7月3日に提出する** | 7gatsu3nichi ni teisyutu suru |
| **昨日のミーティングのメモを残しておいて** | きのうのミーティングのメモをのこしておいて |

## 使う場面

- **常時適用**。ユーザーの生入力（ローマ字・未変換・かな混じり）は、依頼を待たずその場で清書してから解釈・処理・記録する
- 返答の冒頭に `【清書】**文**` を太字で示す（指示・依頼・記録対の入力は必ず。雑談レベルでは省略可）
- ログ・要件台帳・セッション目次などへ載せる時は清書文をそのまま使う
- 入力がローマ字・未変換で読みにくい時（常時なので問わない）
- 意味が確定できない時は候補3つで聞き直す（勝手に判断しない）
