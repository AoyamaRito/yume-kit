# design-system — 単機能・直列 Web アプリ設計思想

多機能メガツール時代から単機能・超速完走ツールへのパラダイムシフト。AI が自律的・迷いなく高品質な Web アプリを構築するための設計思想。

## 核心概念

1. **根本仮説「なぜ単機能か」**: 「色々できる理由がない。」今やりたいこと 1 つが、1 秒で、最高の手触りで終わる単機能ツールが正解。
   - ノイズの排除（多機能＝迷い・視界の濁り・ロードの遅延）
   - 研ぎ澄まされた切れ味（起動した瞬間に主役があり、3 ステップでゴールに届く）
   - 企画意図（Why）の 100% 宿留

2. **企画意図からの逆算（Who / What / Outcome）**:
   - **誰が（Who）**: どんな状況・心理状態のユーザーか？
   - **何を（What）**: どんな素材・データ・入力を持ってくるか？
   - **どうしたいのか（Outcome）**: どんな成果物を手に入れて、どう終わりたいか？
   - この 3 つが定まらない限り、1 行の CSS も 1 つのボタンも配置してはならない。

3. **主要 UI と枝葉 UI の峻別**:
   - 画面上の要素を「同じ強さ・同じ顔」で並べることを固く禁ずる
   - UI は常に**主役**と**舞台裏**に二分される
   - 主要 UI（面積 85-90%）: 画面を開いた瞬間 0.1 秒で視線が吸い寄せられる太い主動線
