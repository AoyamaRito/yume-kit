# Bootstrap Discipline (Start cheap)

1.  **Scan (Always)**: At the start of work, always read the following indices/logs:
    *   `.pi/ctxlog.jsonl` (latest first, then search by tag)
    *   `.pi/session-index.md` (for detailed history if needed)
    *   `AGENTS.md` (this guideline - in pi_root)
    *   `00_ENTRY.md` (workspace map - in pi_root)
    *   Project-specific `README.md` / `DESIGN.md`
2.  **Start Cheap**: After scanning, find the easiest surface to modify.
3.  **Impact Assessment**: Investigate dependencies before expanding scope.
4.  **Targeted Read**: Then, `expand` (or deep read) + edit + `apply`.
