# log-clean — 入力の清書（ログ用・常時適用）

ユーザーの生入力（ローマ字・漢字未変換・かな混じり）を、**意味を一切変えずに**読みやすい日本語へ清書し、ログに載せられる形で返す規約。**常時適用**（依頼を待たない）。

## ルールの要旨

1. **意味は一切変えない**（最優先）
2. **文字もできるだけ変えない** — ローマ字→日本語表記・未変換かな→漢字・句読点や表記揺れの整理だけ
3. **確定できない時は候補を 3 つ提示して聞き直す**（勝手に決めない）
4. ローマ字入力は想定済み（`kyou` → 今日 など）

## 出力フォーマット

- 返答の冒頭に `【清書】<文>` を**太字＋色付きで強調**して示す（指示・依頼・記録対象の入力は必ず）
- **原典（生入力）は強調の逆（小さく・薄く）で併記**する（対照確認用）
- ログ・台帳には清書文をそのまま使う

```text
ユーザー: asita no 12ji ni kaigi site hoshii
AI:      【清書】明日の12時に会議してほしい
         （asita no 12ji ni kaigi site hoshii）←小さく薄く
```
