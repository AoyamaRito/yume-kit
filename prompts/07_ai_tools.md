# ai-tools — 「見えないものを見る」ための道具箱

AI エージェントが**「見えないものを見る」ための道具**の集合。それぞれ独立した CLI。

## 構成

| ツール | 何をする | いつ使う |
|---|---|---|
| **asset-gen** | fal.ai API（Recraft v3 / Flux）で 2D イラスト・ゲームアセット生成。キャラ同一性・絵柄保持・表情/ポーズパック一括生成・HTML ビューア | ゲーム素材・キャラ立ち絵・背景を生成したい時 |
| **ui-graph** | ブラウザ内部からロジカルグラフ（包含/スタック/遮蔽/A11y）を自動抽出し、はみ出し（overflow）・遮蔽（occlusion）を即時検出 | Web UI のデバッグ・レイアウト検証・CI 合否判定 |
| **ascii-3d** | 3D 地形を文字列で直描き（俯視/透視/断面/影/チャンネル/ムービー/検証）。アプリと同じ生成ロジックを Node で再現＝無損失のグラウンドトゥルース | 地形の構造・統計・バッチ QA |
| **webqa** | ヘッドレス Chrome でスクショ・パリティ検証・ピクセル解析（穴/スリット/色） | アプリの実動作を機械検証する時 |
| **vision-qa** | 画像をマルチモーダル AI に渡して日本語レポート化 | 「雰囲気・テイスト・崩れ」の定性評価（最終判断は人間の目） |
| **monte-carlo-test** | 実ブラウザで DOM をランダム操作し、壊れ（遮蔽・連続エラー・暴走）を機械探索 | Web UI を LLM の腕前に頼らず機械で担保したい時 |
| **ga4-monitor** | GA4 データの鮮度・ボリューム異常・受信経路を自前で継続監視 | GA4 にデータが流れてるか常時確認 |

## 使いどころの原則

- 静的検証（ui-graph）と機械探索（monte-carlo）は役割分担
- 定性評価（vision-qa）は参考。テイスト判断は人間の目が最終
