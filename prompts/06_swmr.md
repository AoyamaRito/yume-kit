# swmr-pi — Single Writer / Multiple Readers（協調・運用）

AI 自走開発の並列化原則を pi.dev 上で実現する運用システム。

## 核心原則

> **コードは並列化しない。情報だけ並列化する。**
> Read は水平スケールする。Write は水平スケールさせない。

- **設計・実装は直列（planner → dev）で 1 件ずつ**。MAIN はヒアリングと要件台帳のみ
- **Reader（調査）は read-only で並列可**。Reader に write 権限を与えない
- **最終判断は人間**

## 要件台帳（ヒアリング層 → 校正層 → 実装層）

人間の要求を整理した議事録として残す（正本: `swmr-pi/DESIGN.md` §5）。

- **思考ログは残さない**（計算であって成果物ではない。未来の AI のノイズになる）
- 残すのは「人間の原文」と「AI の校正+仮定」の**交互**
- 校正層に**仮定・不明点・矛盾**を明示し、誤解が「仮定の誤り」として検出・修正できるようにする
- 台帳は隔離された文脈たちの唯一の共有メモリ

## 役割

- **MAIN**: ヒアリング・要件台帳・ルーティング・人間への提示（設計しない・実装しない・判断しない）
- **planner**: 要件と調査結果から設計 + パケット作成（read-only）
- **research / inspect**: 並列スポーン。read-only で情報を集め圧縮して返す
- **dev**: 直列で 1 体だけ。パケット（最小スコープの文脈）を受け取り実装する
- **function-tester**: E2E 通過後、仕様を知らない別プロセスで unit test を追加する
